# رادار اللوحات 📡

برنامج ويب للتعرف الصوتي على أرقام وحروف لوحات السيارات المصرية، وربطها بقاعدة بيانات (مطلوبة / سليمة).

## الاستخدام
افتح ملف `index.html` في المتصفح (كروم يفضل)، أو فعّل GitHub Pages للريبو ده عشان تفتحه من رابط مباشر.

### مميزات البرنامج
- 🎨 شكل جديد بألوان بنفسجية/كحلية عصرية بدل الأزرق-التركواز، مع خلفية متدرجة ناعمة وتأثيرات حركية خفيفة.
- ☰ **قائمة جانبية على يمين الصفحة**: فيها الإعدادات كلها ومفتاح تبديل الوضع الليلي/النهاري بشكل واضح ومباشر.
- 📄 الملف بقى صفحة HTML كاملة بعنوان وأيقونة PWA، جاهزة تتفتح كموقع مستقل على GitHub Pages.
- 🎤 بحث صوتي بالنطق المصري للوحات **السعودية** (أرقام وحروف)، وتقدر تقول أكتر من لوحة كاملة ورا بعض في نفس التسجيلة — البرنامج بيفرّق بينهم لوحده من غير ما يحتاج وقفات، ويطلعلك نتيجة كل لوحة لوحدها. سطر "سمعت: ..." بيوريك اللي اتفهم أول بأول.
- 🔢 بيفهم الأرقام رقم رقم ("واحد تسعة تسعة ستة") أو مركّبة بالمصري ("ألف وتسعمية وستة وتسعين") - والاتنين بيشتغلوا صح.
- 🔤 بيفهم الحروف عربي أو إنجليزي، متصلة أو منفصلة، حسب الجدول الرسمي لحروف اللوحات السعودية.
- 🧾 جدول نتائج الجلسة (الحالة / الأرقام / الحروف) بيتراكم مع كل لوحة بتتفحص، وزرار "↩️ تراجع" يشيل آخر لوحة منه.
- 🔈 نطق النتيجة بالصوت (اختياري) + صفارة تنبيه للحالة المطلوبة.
- 🗺️ **تاب الخريطة الجديد**: كل السيارات المطلوبة اللي ليها موقع على خريطة واحدة تفاعلية، بدل ما تفتحيهم واحدة واحدة.
- 📍 **ترتيب حسب الأقرب**: زرار يحدد موقعك ويرتب قائمة المطلوبة حسب أقرب مسافة، مع تنبيه صوتي لو في سيارة مطلوبة على بعد أقل من كيلومتر منك.
- ✅ **تحديد جماعي (Bulk actions)**: حددي كذا لوحة مع بعض من تاب المطلوبة أو السليمة، وانقليهم أو احذفيهم كلهم دفعة واحدة.
- 📋 نسخ رقم وحروف أي لوحة بضغطة واحدة.
- 📋 تاب "الكل": يجمع كل السيارات في القاعدة، مع نسبة وضوح الصوت، وعدد السليمة/المطلوبة، ورسم بياني لعدد عمليات البحث حسب الساعة، وأزرار تنزيل ملونة (الكل / المطلوبة / السليمة)، وزرار 🖨️ طباعة/PDF.
- 📤 مشاركة أي سيارة مطلوبة على واتساب بضغطة واحدة.
- 📁 رفع ملف إكسيل من الهيدر أو من داخل تاب "المطلوبة" مباشرة — بيقرا كل الشيتات، وبيفصل الحروف عن الأرقام تلقائي حتى لو مكتوبين مع بعض.
- 📍 تحديد موقع لكل سيارة (كتابة يدوية أو "استخدم موقعي الحالي")، مع رابط يفتح على خرائط جوجل مباشرة.
- 🚨 خانة السيارات المطلوبة، ✅ خانة السليمة — كل خانة فيها بحث/فلترة، وتعديل الحالة والملاحظات والموقع، وحذف، وتحميل الملف.
- 🗂 سجل نشاط كامل (بحث + تعديلات + حذف + استيراد) موضّح فيه مين عمل ايه، قابل للتحميل كإكسيل.
- 📄 تصدير تقرير يومي/أسبوعي.
- شريط تنقل سفلي سريع، وعداد "لوحات الجلسة".
- ⚙️ إعدادات: اسم المستخدم (يتسجل في السجل)، تفعيل/إلغاء الصوت، وقفل بالرقم السري (PIN)، ومسح كل اللوحات المسجلة.

## تفعيل GitHub Pages
1. Settings → Pages
2. Source: `Deploy from a branch`
3. Branch: `main` / folder: `/ (root)`
4. هيديك رابط زي: `https://username.github.io/repo-name/`
